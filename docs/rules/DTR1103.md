# DTR1103: Avoid async void methods

| Property           | Value       |
| ------------------ | ----------- |
| Category           | Reliability |
| Default severity   | Warning     |
| Enabled by default | Yes         |

## Cause

A method or local function uses `async void`.

Conventional event handlers with parameters `(object, EventArgs)` are
not reported.

## Why this matters

The caller cannot await an `async void` operation. Exceptions cannot
be observed through a returned task, and completion cannot be tracked
reliably.

## Noncompliant code

```csharp
public async void SaveAsync()
{
    await repository.SaveAsync();
}
```

## Compliant code

```csharp
public async Task SaveAsync()
{
await repository.SaveAsync();
}
```

Event handlers may return `void`:

```csharp
private async void Button_Click(
object sender,
EventArgs eventArgs)
{
await SaveAsync();
}
```

## Configuration

```csharp
{
  "rules": {
    "DTR1103": {
      "enabled": true,
      "severity": "warning"
    }
  }
}
```

## Limitations

Custom event delegate signatures that do not follow the conventional
(object, EventArgs) pattern may currently be reported.
